# Day 4 - Mini Project

## Student Marks Calculator

This is a simple Python program that calculates a student's total marks, average marks, and grade.

## Concepts Used

- Variables
- User input
- Data types
- Arithmetic operations
- If-elif-else conditions

## How It Works

1. The user enters their name.
2. The user enters marks for three subjects.
3. The program calculates the total.
4. The program calculates the average.
5. The program assigns a grade based on the average.

## Example

Input:

Name: Joel
Subject 1: 80
Subject 2: 75
Subject 3: 90

Output:

Total: 245
Average: 81.67
Grade: B
